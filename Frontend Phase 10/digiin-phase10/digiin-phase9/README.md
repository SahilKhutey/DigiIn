# DigiIn Frontend — Phase 9

Phase 9 adds the Identity, Trust, Privacy, Security, Audit and Developer/API foundation on top of the Phase 8 organisation portal.

## Included
- DigiIn account identity and DigiIn ID
- Organisation identity and trust status
- Purpose-bound permission centre
- Connected organisations
- Permission revocation
- Security centre and active sessions
- Unified audit/activity timeline
- Organisation developer portal
- Scoped API client lifecycle
- One-time demo secret display
- Webhook management
- DigiIn API v1 contract documentation
- API request simulator
- Phase 5–8 flows preserved

## Run

```bash
npm run dev
```

Then open the local server shown by the command.
