# DigiIn — Phase 13: Verification Engine & Cryptographic Proof Infrastructure

Deterministic verification engine, evidence collector, and Ed25519 verifiable proof infrastructure.

## Key Subsystems

1. **Deterministic Verification Engine (`apps/api/src/modules/verification/`)**:
   - Evaluates versioned rules (`DOCUMENT_SOURCE_VALID`, `DOCUMENT_CHECKSUM_VALID`, `DOCUMENT_TYPE_VALID`, `ISSUER_PRESENT`, `ISSUE_DATE_VALID`, `DOCUMENT_NOT_EXPIRED`) against isolated `VerificationContext`.
2. **Explainable Results & Confidence**:
   - Collects observable `VerificationEvidence` and outputs structured decisions (`VERIFIED`, `HIGH` confidence).
3. **Cryptographic Proof Infrastructure (Ed25519)**:
   - Digital signatures generated by `ProofSigningService` with key rotation support (`KEY-2026-01`).
   - Selective disclosure claim model (`EDUCATION_VERIFIED`) eliminating raw document leakage.
4. **Public Verification & QR Interface**:
   - Independent proof validation via `GET /v1/public/proofs/:id/verify`.
   - QR code dynamic verification endpoint (`verify.digiin.in/p/:id`).
   - Real-time proof revocation (`POST /v1/proofs/:id/revoke`).
5. **Prisma & PostgreSQL Schema (`prisma/schema.prisma`)**:
   - `Verification`, `VerificationEvidence`, `VerificationRuleResult`, `VerificationResult`, `Proof`, `ProofRevocation`, `SigningKey`.
