# DigiIn Frontend Foundation — Phase 1

Runnable, dependency-free frontend foundation for the DigiIn citizen document-verification journey.

## Run

```bash
npm run dev
```

Open `http://localhost:4173`.

## Implemented

- UX4G-oriented design tokens
- Responsive application shell
- Skip navigation and focus states
- Mobile navigation
- Public landing page
- Sign-in shell
- Citizen dashboard
- DigiIn ID presentation
- Verification request + consent
- Simulated retrieval/verification progress
- Verification result + share action
- Accessibility/security/help/privacy/terms foundation pages
