# DigiIn Frontend — Phase 2

UX4G-aligned frontend foundation for DigiIn's citizen document verification experience.

## Phase 2 implemented

- Centralized DigiIn design tokens
- Reusable Button, Badge, Card, Alert, Field, Status, DocumentCard, Stepper, EmptyState and Skeleton components
- Accessible focus states and skip navigation
- Responsive application shell and mobile navigation
- Citizen dashboard with DigiIn ID and document vault
- Consent-first verification request
- Verification progress and result
- Shared status vocabulary: verified, pending, retrieving, verifying, failed
- Semantic live status regions
- Reduced-motion support

## Run

```bash
npm run dev
```

The project intentionally uses a dependency-free browser foundation in this phase so it can run without a package install.
