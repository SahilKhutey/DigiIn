# DigiIn Frontend — Phase 3

UX4G-aligned public website and citizen verification foundation for the DigiIn hackathon build.

## Phase 3 implemented

- Public DigiIn homepage
- About DigiIn
- How DigiIn works
- For citizens
- For organisations
- Security & privacy
- Accessibility
- Help & FAQ
- Contact form demo
- Privacy notice
- Terms of service
- Existing sign-in, citizen dashboard and verification journey retained
- Responsive public navigation and footer
- Semantic content sections and accessible FAQ disclosure
- Demo-only contact interaction

## Run

```bash
npm run dev
```

Then open `http://localhost:4173`.

No package installation is required for the current foundation build.
