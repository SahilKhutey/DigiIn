# Phase 4 Trust Model

DigiIn now distinguishes four layers:

1. **Evidence** — uploaded or externally received material.
2. **Claims** — structured facts extracted from evidence.
3. **Verification decision** — an authorized process establishes which claims are trusted.
4. **Credential** — a durable, issuer-bound representation of verified claims.

A document must never become trusted merely because OCR succeeded.

OCR is an extraction mechanism, not an authority.

Government or authorized issuer review establishes verification.

Credential signing/proof issuance happens only after approval.
