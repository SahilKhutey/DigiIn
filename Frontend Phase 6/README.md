# DigiIn Frontend — Phase 6

Runnable frontend foundation for DigiIn Phase 6: Document Verification Engine.

## Run

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Phase 6

- Retrieved-document verification
- Verification state machine
- Integrity / issuer / detail checks (mocked)
- Accessible progress timeline
- Per-document results
- Verified / partial / failed aggregate states
- Verification ID generation and copy
- Verification detail routes
- Service boundary ready for backend integration

Demo mode only: no real documents, issuer APIs, or DigiLocker credentials are used.
